# Matrix Maze Math

saya ingin membuat web app untuk media belajar materi matrix matematika. nama appnya Mahtrix, wajib memiliki fitur pembelajaran, latihan soal, evaluasi, dan login untuk save progress. penggunaan diutamakan untuk mobile, tetapi juga berfungsi dan berpenampilan baik di desktop. gaya desain dan ui wajib kids friendly
